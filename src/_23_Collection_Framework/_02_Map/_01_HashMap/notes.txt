HashMap :
    1. Unordered : It does not maintain any order of its elements
    2. Allows null keys and values : can have only one null key and multiple null values
    3. Not Synchronised : Not thread-safe, Requires external synchronisation if used in a multi-threaded context
    4. Performance : Offers constant time performance (O(1)) for basic operations like get and put, assuming the hash function spreads elements properly

Internal Structure of HashMap :
    Key -> Identifier use to retrieve value.
    Value -> The data associated with key.
    Bucket -> It is a array in which key-value of hashmap is stored on single index. (Initial size = 16)
    Hash function -> Hash function is used to compute a hashCode for a key to determine its bucket location
    takes the key from bucket into index for storage. It is algorithm that takes a key and returns fixed size string of bytes, typically a numeric value. The output is known as hashcode or hash value or simply hash. It will always produce the same output for the same input. This is a fast algorithm. (Converts a key into an index (bucket location) for storage)

How data is stored in HashMap :
    Step 1 -> Hashing the key,
        The key is passed through hash function so that unique hashcode is generated. So according to hashcode, key value pair is stored in array (called bucket array).
    Step 2 -> Calculating the index
        The hash code is then used to calculate an index in the array(bucket location) using formula = int index = hashcode % arraySize.
        This index decides which bucket will hold this key-value pair.
        e.g. If the array size is 16, the key's hashcode will be divided by 16 and remainder will be the index
    Step 3 -> Storing in the bucket
        The key-value is stored in the bucket at the calculated index. Each bucket can hold multiple key-value pairs (This is called collision handling mechanism)

    Collision handling -> different keys can generate same hashcode so that it can be stored in same index of array and there collision handling happen.

    So, how multiple key-value stored at same it is because, every key-value stored as a linkedlist at an index.

    Rehashing = As we know capacity of ArrayList can be increase or decrease with the help of threshold, We can use same mechanism for Bucket as well. Initial threshold for bucket is 0.75
