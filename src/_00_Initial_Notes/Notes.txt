Introduction to Java :

    1] What is Programming :
        Programming is set of instructions that tell computer how to perform task.
        Programming can be done using variety of computer programming languages like C, C++, Java, JS, Python.

    2] Category of Programming languages :
        Programming languages can be categorised into
            1] High level language -> Human understandable language
            2] Assembly language -> consist of binary characters expressed in human readable form
            3] Machine level or low level language -> It is made up of binary numbers or bits that machine can understand.

    3] Compilation VS Interpretation :
        Compilation :
            It is a process to convert high level (C, C++, Java) programming language into machine language code that computer can understand. The software which performs this is called compiler.
        Interpretation :
            It is performed by an interpreter which directly executes instructions written in programming language without previously converting them to an object code or machine code. This conversion of code happens line by line. (JS, Python, Ruby)


    4] Types of Programming Paradigms :
        Procedural Programming Paradigm
        Functional Programming Paradigm
        Object-Oriented Programming Paradigm

        Procedural :
            i] The entire program code is organized as a set of procedures that are executed in order.
            ii] These procedures are also known as functions and contain a series of steps that will be carried out when procedure is called.
            iii] e.g. C, FORTRAN, BASIC, COBOL, ALGOL, PASCAL.

        Functional :
            i] This program code is organized in pure functions (which always yields the same value for same set of input without any deviation) with each function set up to perform clearly defined tasks.
            ii] The data / variables are passed in the function as parameters for the function to interact with other functions or programs.
            iii] Language that supports this approach are JavaScript, Python etc.

        Object-Oriented :
            i] The program data is organized in classes and objects rather than functions and logic.
            ii] A class is blueprint for creating objects and an object is referred to as an instance of a class that has unique attributes and behaviour.


    5] About Java :
        i] Java is class based object-oriented programming language which make it easy to write, compile and debug code.
        ii] Java developed by James Gosling in 1995, and it is later acquired by Oracle corporation.
        iii] Java used to develop web application, mobile application, big data processing and embedded system.


    6] Features of Java :
        i] Simple :
            Java is considered simpler than C++ because it removes many complex features like pointers, manual memory management, header files, operator overloading, and multiple inheritance.
            Java also provides automatic garbage collection and runs inside JVM, which makes development easier and safer.
        ii] Portable :
            Java is a platform independent programming language because it converts code into bytecode, which can run on any system using JVM.
            Platform = Processor + Operating System
                e.g. P1 = X86 + Windows
                     P2 = ARM + MacOS
            So why in case of C++, platform generates different bytecode and how same same compiled byte code of Java can be run on any platform?
                C++ directly talks to the processor and operating system, it must create different machine code for each platform.
                    1. With Context of OS :
                        Different OS has different commands in their library to process the code
                        For example, printing text may use different system commands in Windows and MacOS, therefore the compiled code becomes different for each platform.
                    2. With Context of Processor :
                        Processor only understands its own ISA (Instruction Set Architecture), which is the set of machine instructions a CPU can execute. Different processors like x86 and ARM have different ISAs, so C++ compiler must generate different machine code for each processor type.
                         For example, an instruction generated for x86 may not be understood by an ARM processor.
                    Different operating systems use different system commands, therefore the compiled code becomes different for each platform.
                Java does not directly talk to the processor or operating system.
                It first converts source code into platform-independent bytecode.
                Then JVM converts that bytecode into machine code according to the platform.
                Therefore, JVM must be platform specific.
        iii] Secure :
             Java is fairly simple and secure (Java has automatic garbage collection so you don't have to deallocate memory).
             Java is considered more secure than C++ because Java runs inside JVM, which checks the code and manages memory safely. Java also does not allow direct memory access and pointers, so harmful memory errors are reduced.


    7] Java Architecture :
        General Compilation Process :
            Source code         ->      Compiler / Interpreter         ->       Machine code (0 / 1)
          (java, js, cpp)


        Compilation Process in Java :
        Source code (.java)     ->      javac compiler      ->      Bytecode (.class)       ->      JVM interpreter        ->       Machine code (0 / 1)
            Here,
            Source code = human-readable code with .java extension.
            javac = It compiles source code into bytecode. javac is name of compiler.
            Bytecode = After compiling source code into bytecode it generates .class file. (Bytecode can run on any platform which has JVM installed in it because JVM interprets bytecode into machine code.)
                       This feature of bytecode makes Java platform independent.
                       If you are compiling Java program in Windows platform then it will generate bytecode and that bytecode will run on any platform like macOS, Linux etc.
                       But prerequisite is that JVM must be installed on that platform.
                       In C++, .cpp file generates .exe file on Windows which can run only on Windows machine.
                       That makes C++ platform dependent.
                       So Java is platform independent and portable language.
                       Compile once and run everywhere.
            JVM = Java Virtual Machine
                  JVM is platform dependent because distribution of JVM on Windows, macOS and Linux is different.
                  JVM is interpreter that converts bytecode (.class) into binary language.


    8] Java Architecture Components :
        JVM (Java Virtual Machine)
        JRE (Java Runtime Environment)
        JDK (Java Development Kit)

        JVM : JVM provides runtime environment to execute the bytecode.
              It translates bytecode into machine code.
              Components inside JVM :
                Class Loader : It is responsible for loading your bytecode into the main memory.
                Memory Area : If any program is executing by JVM then it allocates memory where operations take place.
                Execution Engine :  i] Interpreter : It translates code line by line.
                                    ii] JIT Compiler (Just In Time Compiler) : It optimizes the performance of JVM.
                                        Interpreter checks code line by line and if it finds repeated code then JIT compiler converts that repeated piece of code at a time so performance of system gets optimized.
                                    iii] Garbage Collector : It is responsible for de-allocating or de-referencing the unused memory.
                                                             Garbage collector finds unused memory and deletes it so we don't have to do that manually like we do in C++.

        JRE : Java Runtime Environment
            JRE is nothing but Java libraries like collection, math etc, that we import in our java code.
            JRE provides those libraries.
            JRE = JVM + Runtime Libraries

        JDK : Java Development Kit
            JDK provides tools like javac, debugging tools, monitoring tools, javadoc.
            JDK = JRE + Development Tools
